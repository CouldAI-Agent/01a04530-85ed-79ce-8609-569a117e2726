# Assessment Proposal

A clean, responsive single-page Flutter application that presents a professional assessment proposal.

## Features
- **Responsive Layout:** Automatically adapts to mobile, tablet, and desktop/web widths.
- **Structured Content:** Separated into clear, easy-to-read sections including Executive Summary, Objectives, Scope, Timeline, and Investment.
- **Call to Actions:** Interactive buttons to accept the proposal or download a PDF (with mock snackbar feedback).
- **Modern UI:** Uses Material 3 with a refined color palette, subtle borders, and elevated typography.

## Tech Stack
- Flutter
- Dart
- Material 3 Design System

## Getting Started

1. Ensure you have Flutter installed.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the app on your preferred platform (iOS, Android, Web, macOS, Linux, or Windows).
